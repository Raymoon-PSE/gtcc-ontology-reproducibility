Implementation scope fixed before paired case results, 13 October 2026.

The broad design is narrowed to a representation/adapter comparison. Identical explicit engineering facts feed RDF/RDFS and centralized indexed JSON. Validators, numerical kernels, converters and revision algorithm are shared. Equality is a plausible expected outcome, not a failure to hide.

S1 exercises a NEW external subtype gate, using multi-hop ancestry and an explicit binding to the existing GT expander kernel. It does not claim the old EKLM runtime automatically discovers model classes.
S2 routes HP-ST through an actual common versioned same-kernel adapter. It does not introduce a new physical model.
S3/S4 adapters run at actual physical solver input boundaries, including the iterative steam-water return loop. The physical execution order remains Python-configured.
S5 uses a NEW explicit revision envelope and complete consumer manifest around actual full physical/mechanical/diagnostic runs. This tests declared revision consistency, not arbitrary data-lineage authenticity or a dependency scheduler. All consumers rerun; no selective update is claimed.
S6 migrates the EXPORTED superheater output schema after internal diagnostics. Output-contract, publisher, query and warning-export gates check the declared schema version. They are compatibility gates in a common export adapter, not four independently implemented applications or a full internal diagnostic schema rewrite. Existing warning content must remain equal.

JSON mechanics setup is prepared once from current source configuration, including class closure, and revalidates it without Graph operations during execution. Whole mechanical runtime latency is therefore NOT a fair raw-input representation timing comparison. Performance claims use a separate matched primitive-fact parse/lookup benchmark, with identical hierarchy information and queries for both arms.

Before/after native artifacts and logical fact diffs are retained. Since equivalent fixtures are generated from common facts, equal edit counts demonstrate fixture configuration parity, NOT experimentally measured human maintenance effort or ontology superiority. No developer study was conducted.

Acceptance oracles: original unadapted linked-cycle physics at ambient 5,15,25C; full-loop convergence; external mass residual <1e-6 kg/hr and energy residual <0.01 kW (existing linked-cycle tests); finite numerical parity rtol1e-10 atol1e-6 for values with exact metadata/status checks. Tolerances allow floating-point unit round trips and are fixed before comparing arms. Baseline repeatability is separately recorded; do not claim an empirical tolerance fit. Failed comparisons remain failures, not grounds for loosening thresholds.

Stored initial protocol and this amendment are local pre-run records, not external preregistration or blinded study registration. No operating-plant data or human productivity outcomes are generated by this experiment.
